# ✅ ① 项目详细说明文档（RAG系统）

# 📌 Production RAG System（检索增强生成系统）

## 1. 项目概述

本项目是一个**生产级 Retrieval-Augmented Generation（RAG）系统**，用于构建“基于知识库的智能问答系统”。系统结合：

* 大语言模型（LLM）
* 向量数据库（Vector DB）
* 信息检索系统（Retrieval）
* 文档处理与评估模块

实现一个可以“**先查资料，再生成答案**”的智能问答框架。

---

## 2. 系统核心思想

RAG = Retrieval（检索） + Augmented（增强） + Generation（生成）

### 工作流程：

```
用户问题
   ↓
问题向量化（Embedding）
   ↓
向量数据库检索相关文档
   ↓
返回Top-K知识片段
   ↓
拼接Prompt（问题 + 知识）
   ↓
LLM生成最终答案
   ↓
输出结果（可带引用）
```

---

## 3. 系统模块设计

### 📁 3.1 数据层（Data Layer）

* DataLoader：加载 PDF / TXT / MD / DOCX / HTML
* DocumentSplitter：文本切块（chunking）
* Metadata管理：记录来源、页码、标签

👉 作用：把非结构化数据变成可检索知识

---

### 🧠 3.2 向量层（Embedding Layer）

* OpenAI Embedding
* SentenceTransformers
* HuggingFace模型

👉 作用：
将文本 → 向量（语义空间表示）

---

### 🗄️ 3.3 向量数据库（Vector Store）

支持：

* ChromaDB（本地）
* Qdrant（生产级）
* Redis（缓存+检索）

👉 作用：
存储向量 + 支持相似度搜索

---

### 🔍 3.4 检索层（Retrieval Layer）

包含：

* Dense Retrieval（向量检索）
* Sparse Retrieval（BM25关键词）
* Hybrid Search（混合检索）
* Reranker（交叉编码器重排序）

👉 作用：
提高“找资料”的准确性

---

### 🤖 3.5 生成层（LLM Layer）

支持：

* OpenAI GPT-4 / GPT-3.5
* Azure OpenAI

功能：

* Prompt构造
* 上下文增强
* 流式输出（Streaming）

---

### 🔁 3.6 RAG Pipeline（核心编排层）

统一流程：

```
query → embedding → retrieval → rerank → prompt → LLM → answer
```

👉 是整个系统的“中枢神经”

---

### 🌐 3.7 API服务层（FastAPI）

提供接口：

* /query（问答）
* /upload（上传文档）
* /evaluate（评估）
* /health（健康检查）

支持：

* REST API
* Swagger文档
* 流式响应

---

### 📊 3.8 评估系统（Evaluation）

指标：

* Faithfulness（是否胡编）
* Relevancy（相关性）
* Precision（精度）
* Recall（召回）

👉 用于衡量RAG质量

# ✅ ② 运行该项目所需硬件配置

## 🖥️ 1. 最低配置（可跑但较慢）

适合：开发 / 学习 / demo

* CPU：4 核
* 内存：8 GB
* 硬盘：SSD 20GB
* GPU：❌ 不需要
* 网络：普通宽带

👉 可运行：

* SentenceTransformer
* 本地ChromaDB
* 小规模文档（<1万条chunk）

---

## 🚀 2. 推荐配置（开发 + 小规模生产）

适合：毕业设计 / 项目部署 / 小型系统

* CPU：8 核+
* 内存：16–32 GB
* 硬盘：SSD 50–100GB
* GPU（可选）：RTX 3060 / 4060

👉 可支持：

* Qdrant向量库
* Hybrid Search
* rerank模型
* 中等规模知识库（10万 chunk）

---

## 🧠 3. 高性能生产配置（企业级）

适合：公司级知识库 / 高并发系统

* CPU：16–32 核
* 内存：64–128 GB
* GPU：A100 / H100 / 4090 ×1–4
* 存储：1TB+ NVMe SSD
* 网络：千兆/万兆

👉 可支持：

* 百万级文档检索
* 多用户并发问答
* 大模型本地部署（Llama / Qwen）
* 实时流式生成
