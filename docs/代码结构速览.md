## 一、目录结构

```
rag_project/
├── main.py                  # CLI 入口（index / query / chat / server / evaluate）
├── api/
│   ├── main.py              # FastAPI 服务入口（HTTP 接口层）
│   └── schemas.py           # Pydantic 数据模型（请求/响应结构）
├── src/                     # 核心业务逻辑
│   ├── __init__.py
│   ├── rag_pipeline.py      # 主编排器（串联所有模块）
│   ├── data_loader.py       # 文档加载（PDF/TXT/MD/DOCX/HTML）
│   ├── document_splitter.py # 文档切分（递归切分 + section_path 注入）
│   ├── embedding_model.py   # Embedding 模型（BGE/OpenAI/HuggingFace）
│   ├── vector_store.py      # 向量数据库（ChromaDB/Qdrant/Redis）
│   ├── retriever.py         # 检索器（混合检索 + Reranker）
│   ├── generator.py         # LLM 生成层（OpenAI/Azure，流式支持）
│   └── evaluation.py        # 评估指标（Faithfulness/Relevancy/Precision/Recall）
├── config/
│   ├── settings.yaml        # 系统配置（模型/检索/pipeline 参数）
│   └── prompts.yaml         # Prompt 模板（9条防幻觉规则）
├── data/
│   ├── raw/                 # 原始文档（放这里再索引）
│   ├── chroma_db/           # ChromaDB 向量库持久化
│   └── keyword_index.pkl    # jieba 关键词索引持久化
└── docs/                    # 技术文档
```

## 二、模块职责一览

| 文件 | 职责 | 关键类/函数 |

## 三、数据流：索引阶段

```
python main.py index --source data/raw/
         │
         ▼
RAGPipeline.index_documents()
         │
         ├─ DataLoader.load_directory()
         │       ├─ _load_pdf()
         │       │     ├─ pypdf 提取文本 + [PAGE:N] 标记
         │       │     ├─ _extract_outline()      → PDF 书签 → _page_to_section 映射
         │       │     └─ _detect_toc_pages()     → 目录页集合，跳过不索引
         │       └─ 返回 List[Document]
         │
         ├─ RecursiveCharacterSplitter.split_batch()
         │       ├─ _recursive_split()            → 按 \n\n / \n / ". " / " " 递归切分
         │       ├─ 注入 section_path             → 从 _page_to_section 查表
         │       ├─ base_metadata 过滤            → 只保留标量类型（ChromaDB 兼容）
         │       └─ _merge_small_chunks()         → 合并 < 50 字符的碎片块
         │
         ├─ EmbeddingModel.embed_documents()      → 批量向量化
         │
         ├─ VectorStore.add()                     → 写入 ChromaDB
         │
         └─ HybridRetriever.build_keyword_index() → jieba 分词建倒排索引 → pickle 持久化
```

## 四、数据流：查询阶段

```
pipeline.query("什么是函数？")
         │
         ├─ _rewrite_question()                   → 含指代词时 LLM 改写（多轮消歧）
         │
         ├─ AdvancedRetriever.retrieve()
         │       ├─ HybridRetriever.retrieve()
         │       │     ├─ EmbeddingModel.embed_query()  → 查询向量化（bge 加前缀）
         │       │     ├─ VectorStore.search()          → 向量检索 Top-10
         │       │     ├─ _keyword_search()             → jieba 分词 + TF-IDF Top-10
         │       │     └─ _fuse()                       → 归一化加权融合（0.7/0.3）
         │       └─ Reranker.rerank()（可选，默认关闭）  → sigmoid 归一化后加权融合
         │
         ├─ 相似度阈值过滤（final_score ≥ 0.3）
         │
         ├─ 无关问题检测（vector_score < 0.3 → 直接返回拒答）
         │
         ├─ _build_context_with_budget()
         │       ├─ tiktoken 精确计数（降级字符估算）
         │       ├─ 前置 [文件名 | 章节名] header
         │       └─ 超出预算时整体跳过 chunk（不截断）
         │
         ├─ ConversationManager（多轮对话）
         │       ├─ 最近 2 轮完整保留
         │       └─ 更早轮次 LLM 增量压缩成摘要
         │
         ├─ PromptManager.get('system.rag_assistant')   → 9条防幻觉规则
         │
         ├─ 动态生成预算：min(配置值, 窗口 - 输入token)
         │
         ├─ OpenAIGenerator.generate()                  → 调用 DeepSeek API
         │
         ├─ _fix_citations()                            → 过滤超出范围的引用序号
         │
         └─ 返回 RAGResponse(answer, sources, metadata)
```

```

    ├── DataLoader              加载文档
    ├── RecursiveCharacterSplitter  切分文档

    │       └── HybridRetriever
    │               ├── BaseVectorStore（向量检索）
    │               ├── BaseEmbeddingModel（查询向量化）
    │               └── _keyword_index（jieba 倒排索引）
    ├── BaseGenerator           生成（OpenAI / Azure）
    │       └── PromptManager   Prompt 模板管理
    ├── ConversationManager     多轮对话历史管理
    └── RAGEvaluator（可选）    质量评估
```

## 六、两个入口的区别

| | `main.py`（CLI） | `api/main.py`（FastAPI） |
|---|---|---|
| 启动方式 | `python main.py chat` | `uvicorn api.main:app` |
| 使用场景 | 本地开发、调试、批量索引 | 生产部署、前端调用 |
| 多轮对话 | ✅ `chat` 命令，内存维护历史 | ❌ 无状态，每次独立请求 |
| 流式输出 | ✅ `--stream` 参数 | ✅ SSE（Server-Sent Events） |
| 文档上传 | 通过 `--source` 指定路径 | `POST /upload` 接口 |
| 核心逻辑 | 共用同一个 `RAGPipeline` | 共用同一个 `RAGPipeline` |

## 七、配置文件速查

**`config/settings.yaml`** — 所有运行参数

```yaml
llm:
  model: "deepseek-chat"          # LLM 模型
  base_url: "https://api.deepseek.com"

embedding:
  model: "BAAI/bge-small-zh-v1.5" # Embedding 模型（本地）

document:
  default_chunk_size: 256         # 切分粒度
  default_chunk_overlap: 30       # 重叠字符数

retrieval:
  similarity_threshold: 0.3       # chunk 过滤阈值
  off_topic_threshold: 0.3        # 无关问题拦截阈值
  hybrid_search:
    vector_weight: 0.7
    keyword_weight: 0.3

pipeline:
  keep_recent_turns: 2            # 完整保留最近 N 轮
  max_total_tokens: 7000          # 总 token 预算
```

**`config/prompts.yaml`** — Prompt 模板

- `system.rag_assistant`：默认问答，9条防幻觉规则
- `system.conversational`：多轮对话，携带历史摘要
- `system.concise` / `system.detailed`：简洁/详细模式

## 八、工厂模式说明

项目中大量使用工厂模式，通过配置文件动态选择实现：

```python
# 根据 settings.yaml 中的 provider 字段自动选择
EmbeddingModelFactory.create(config)   # openai / sentence-transformers / huggingface
VectorStoreFactory.create(config)      # chroma / qdrant / redis
GeneratorFactory.create(config)        # openai / azure
SplitterFactory.create(type)           # recursive / semantic / fixed
```

切换底层实现只需改 `settings.yaml`，不需要改代码。
