# 召回架构优化

参考来源：召回架构对比文档.md — 三、当前架构可改进的地方
改动文件：`src/retriever.py`、`src/rag_pipeline.py`

---

## 一、优化总览

| 优先级 | 问题 | 优化方案 | 涉及文件 |
|--------|------|----------|----------|
| 1 | 关键词索引未初始化，混合检索退化为纯向量检索 | 索引完成后自动构建并持久化关键词索引 | `rag_pipeline.py` |
| 2 | 中文分词缺失，关键词检索对中文无效 | 引入 jieba 分词，降级兼容空格切分 | `retriever.py` |
| 3 | 词权重无差异化，专有名词和虚词等权 | 名词（jieba 词性 n 开头）重复加入索引，权重翻倍 | `retriever.py` |
| 4 | Rerank 分数简单平均，量纲不一致 | sigmoid 归一化 Cross-Encoder 分数后加权融合 | `retriever.py` |
| 5 | 空结果无降级，直接返回空列表 | 扩大候选范围重试一次 | `retriever.py` |

## 二、优化一：关键词索引初始化（最关键）

### 问题

`HybridRetriever._keyword_index` 是内存 dict，初始化时为空。`AdvancedRetriever` 在 `RAGPipeline.__init__()` 中创建，此时没有调用 `build_keyword_index()`，导致每次 `_keyword_search()` 都返回空列表，混合检索实际上一直是纯向量检索，关键词权重 0.3 完全没有发挥作用。

### 改动

在 `rag_pipeline.index_documents()` 完成向量入库后，从向量库读取所有 chunk，重建关键词索引并持久化到 `data/keyword_index.pkl`：

```python
# src/rag_pipeline.py — index_documents() 末尾
all_results = self.vector_store.collection.get()
keyword_docs = [
    {"id": all_results["ids"][i], "text": all_results["documents"][i]}
    for i in range(len(all_results["ids"]))
]
self.retriever.hybrid.build_keyword_index(keyword_docs)
self.retriever.hybrid.save_index()
```

`HybridRetriever` 初始化时自动尝试加载持久化索引：

```python
def __init__(self, ...):
    self._load_index()  # 启动时自动加载，无需重新索引
```

**效果**：重新索引一次后，后续每次启动都能直接加载关键词索引，混合检索真正发挥双路召回的作用。

## 三、优化二：中文分词支持

### 问题

原始 `_tokenize()` 用空格切分，中文没有空格分隔词语，导致"什么是函数"被切成["什么是函数"]一个 token，无法匹配索引中的"函数"、"定义"等词。

### 改动

引入 `jieba` 分词，jieba 未安装时自动降级为空格切分：

```python
def _tokenize(self, text: str) -> List[str]:
    try:
        import jieba.posseg as pseg
        tokens = []
        for word, flag in pseg.cut(text):
            if word in self._CN_STOPWORDS or len(word) < 2:
                continue
            tokens.append(word)
            if flag.startswith('n') and len(word) >= 2:
                tokens.append(word)  # 名词重复，权重翻倍
        return tokens
    except ImportError:
        # 降级：空格切分
        ...
```

同时新增中文停用词表（"的"、"了"、"是"等），过滤无意义虚词。

## 四、优化三：词权重差异化

### 问题

原始实现所有词等权，"液压泵型号 HPV-135"中"液压泵"和"型号"权重相同，专有名词没有得到额外加分。

### 改动

利用 jieba 词性标注，名词（词性标签以 `n` 开头，包括 `n`、`nr`、`ns`、`nt`、`nz` 等）在索引时重复加入一次，相当于 TF 翻倍，IDF 加权后权重约为普通词的 2 倍：

```python
if flag.startswith('n') and len(word) >= 2:
    tokens.append(word)  # 名词重复加入，TF ×2
```

这是对 RAGFlow 中 `ner(t) × postag(t)` 词权重机制的简化实现，不需要额外的 NER 模型。

## 五、优化四：Rerank 分数融合优化

### 问题

原始 Rerank 用简单平均：

```python
c.final_score = (c.final_score + c.rerank_score) / 2
```

`final_score` 是 [0, 1] 的归一化分数，`rerank_score` 是 Cross-Encoder 的原始 logit 值（通常在 [-10, 10] 范围），两者量纲完全不同，直接平均会导致 Cross-Encoder 分数主导结果。

### 改动

对 Cross-Encoder 分数做 sigmoid 归一化后加权融合：

```python
@staticmethod
def _sigmoid(x: float) -> float:
    return 1.0 / (1.0 + math.exp(-x))

def rerank(self, ...):
    ...
    c.final_score = 0.3 * c.final_score + 0.7 * self._sigmoid(c.rerank_score)
```

sigmoid 把任意实数映射到 (0, 1)，与 `final_score` 量纲一致。权重 0.7 给 Cross-Encoder，0.3 保留原始混合检索分数，Cross-Encoder 精排结果为主，原始排序作为辅助。

## 六、优化五：空结果降级重试

### 问题

当检索结果为空时（极端情况，如关键词索引刚清空），直接返回空列表，上层 pipeline 会返回"未找到相关信息"。

### 改动

扩大候选范围重试一次：

```python
def retrieve(self, query: str, top_k: int = 5) -> List[RetrievedChunk]:
    results = self.hybrid.retrieve(query, top_k * 2)
    if not results:
        logger.debug("Empty results, retrying with top_k*4")
        results = self.hybrid.retrieve(query, top_k * 4)
    ...
```

## 七、使用说明

优化一（关键词索引）需要重新索引才能生效：

```bash
python main.py index --source data/raw/ --clear
```

索引完成后日志会显示：

```
INFO | Keyword index built: 1535 docs, 12847 terms
INFO | Keyword index saved: data/keyword_index.pkl
```

后续每次启动时自动加载，无需重新索引：

```
INFO | Keyword index loaded: 1535 docs, 12847 terms
```

优化二需要安装 jieba（如果尚未安装）：

```bash
pip install jieba
```

jieba 未安装时系统会自动降级为空格切分并打印警告，不影响运行。
