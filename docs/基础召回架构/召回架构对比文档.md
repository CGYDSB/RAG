## 一、架构总览对比

| 维度 | 当前项目 | RAGFlow |
|------|----------|---------|
| 检索阶段数 | 2（混合检索 → 可选 Rerank） | 4（引擎层融合 → 关键词构造 → 应用层重排 → 引用插入） |
| 向量检索 | ChromaDB 余弦相似度 | ES/Infinity KNN（cosine） |
| 关键词检索 | 内存倒排索引 + TF-IDF | ES query_string + BM25 + 字段权重 |
| 融合策略 | 应用层加权求和（归一化后） | 引擎层 weighted_sum（0.05/0.95）+ 应用层 hybrid_similarity（0.3/0.7） |
| 词权重 | 无（所有词等权） | IDF × NER × 词性（命名实体 ×3，名词 ×2） |
| 同义词扩展 | 无 | 有（权重 ×0.2） |
| Bigram 短语 | 无 | 有（相邻词对权重翻倍） |
| 字段权重 | 无（只有 content） | 标题 ×10，重要关键词 ×30，问题词 ×20 |
| Rerank | Cross-Encoder（可选，默认关闭） | hybrid_similarity 或 Cross-Encoder（均有字段加权） |
| PageRank | 无 | 有（文档重要性加分） |
| 空结果降级 | 无 | 有（降低 min_match 和相似度阈值重试） |
| TOC 辅助召回 | 无 | 有（LLM 分析目录结构补充召回） |
| 父子 Chunk 召回 | 无 | 有（命中子 chunk 自动替换为父 chunk） |
| 关键词索引持久化 | 无（内存态，重启丢失） | ES 持久化 |
| 引用对齐 | 简单序号标注 | 句级向量对齐（hybrid_similarity） |

## 二、逐模块详细对比

### 2.1 关键词检索

**当前项目**：

```python
def _tokenize(self, text: str) -> List[str]:
    text = re.sub(r'[^\w\s]', ' ', text.lower())
    stopwords = {"the", "a", "is", "are", "to", "and", "of"}
    return [t for t in text.split() if t not in stopwords and len(t) > 2]

def _keyword_search(self, query: str, top_k: int) -> List[Dict]:
    tokens = self._tokenize(query)
    scores = defaultdict(float)
    for token in tokens:
        idf = np.log((self._total_docs + 1) / (len(self._keyword_index[token]) + 1))
        for doc_id, freq in self._keyword_index[token].items():
            scores[doc_id] += freq * idf
```

- 分词：空格切分，英文停用词过滤，无中文分词
- 权重：纯 TF-IDF，所有词等权
- 索引：内存 dict，重启后需重建

**RAGFlow**：

- 分词：专用 `rag_tokenizer`，支持中文分词、NER 识别
- 权重：`(0.3 × idf1 + 0.7 × idf2) × ner(t) × postag(t)`，命名实体权重 ×3，名词 ×2
- 字段权重：标题 ×10，重要关键词 ×30，正文 ×2
- 同义词扩展：查询时自动扩展，权重 ×0.2
- Bigram：相邻词对权重翻倍
- 索引：ES 持久化

**差距**：当前项目的关键词检索对中文几乎无效（空格切分无法处理中文），且缺少词权重差异化，专有名词和普通词权重相同。

### 2.2 融合策略

**当前项目**：

```python
# 两路分数各自归一化后加权求和
v_max = max(r["score"] for r in vector_results) or 1.0
k_max = max(r["score"] for r in keyword_results) or 1.0

final_score = 0.7 × (vector_score / v_max) + 0.3 × (keyword_score / k_max)
```

单阶段融合，归一化后直接加权。

**RAGFlow**：

两阶段融合：
- 引擎层：`weighted_sum(0.05, 0.95)`，关键词作为 KNN 的 filter，向量检索主导
- 应用层：`hybrid_similarity(vtweight=0.7, tkweight=0.3)`，归一化后均衡融合

两阶段设计的原因：引擎层 BM25 分数和向量相似度量纲不同，直接加权会导致 BM25 压制向量分数，所以引擎层给关键词只有 5% 权重（主要起过滤作用），应用层拿到归一化分数后再均衡融合。

**差距**：当前项目的单阶段融合在量纲不一致时可能导致关键词分数压制向量分数（或反之），但由于当前关键词索引实际上经常为空（内存态，未调用 `build_keyword_index`），实际上退化为纯向量检索。

### 2.3 Rerank

**当前项目**：

```python
def rerank(self, query: str, chunks: List[RetrievedChunk], top_n: int = 5):
    pairs = [(query, c.text) for c in chunks]
    scores = self.model.predict(pairs)
    for c, s in zip(chunks, scores):
        c.rerank_score = float(s)
        c.final_score = (c.final_score + c.rerank_score) / 2  # 简单平均
```

Cross-Encoder 分数与原始 final_score 简单平均，默认关闭（CPU 环境）。

**RAGFlow**：

```python
# 有模型时：token 相似度 × 0.3 + Cross-Encoder × 0.7 + PageRank
return tkweight * tksim + vtweight * vtsim + rank_fea

# 无模型时：向量 × 0.7 + token 加权相似度 × 0.3
# token 相似度中：标题词 ×2，重要词 ×5，问题词 ×6
```

Rerank 时对不同字段的 token 做差异化权重，标题命中比正文命中权重高 3-6 倍。

### 2.4 关键词索引持久化

**当前项目**：`HybridRetriever._keyword_index` 是内存 dict，每次启动后为空，需要调用 `build_keyword_index()` 重建。但当前代码中 `AdvancedRetriever` 初始化时没有调用这个方法，导致**关键词检索实际上一直返回空结果**，系统退化为纯向量检索。

**RAGFlow**：ES 持久化，重启后直接可用。

## 三、当前架构可改进的地方

按优先级排序：

### 优先级 1：修复关键词索引未初始化的问题

当前 `AdvancedRetriever` 初始化时没有调用 `build_keyword_index()`，关键词检索一直返回空，混合检索退化为纯向量检索。

改进方案：在 `RAGPipeline.index_documents()` 完成向量入库后，从向量库读取所有 chunk 重建关键词索引，并持久化到磁盘（pickle 或 sqlite）：

```python
# rag_pipeline.py index_documents() 末尾
all_records = self.vector_store.get_all()  # 需要新增此方法
self.retriever.hybrid.build_keyword_index(
    [{"id": r["id"], "text": r["text"]} for r in all_records]
)
# 持久化
import pickle
with open("data/keyword_index.pkl", "wb") as f:
    pickle.dump(self.retriever.hybrid._keyword_index, f)
```

### 优先级 2：中文分词支持

当前 `_tokenize()` 用空格切分，对中文完全无效（中文没有空格分隔词语）。

改进方案：引入 `jieba` 分词：

```python
def _tokenize(self, text: str) -> List[str]:
    import jieba
    # 中文用 jieba，英文用空格切分
    tokens = list(jieba.cut(text))
    stopwords = {"的", "了", "是", "在", "和", "与", "或", "等", "a", "the", "is"}
    return [t for t in tokens if t not in stopwords and len(t) > 1]
```

### 优先级 3：词权重差异化

当前所有词等权，专有名词和虚词权重相同。

改进方案：引入简单的词性权重，至少区分名词和虚词：

```python
# 使用 jieba.posseg 获取词性
import jieba.posseg as pseg
def _tokenize_weighted(self, text: str):
    words = pseg.cut(text)
    result = []
    for word, flag in words:
        weight = 2.0 if flag.startswith('n') else 1.0  # 名词权重翻倍
        result.append((word, weight))
    return result
```
