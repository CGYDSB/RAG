具体来说：
1. **作用域是静态确定的**：函数的作用域由其定义所在的模块决定，与调用位置无关 [[2]]。
2. **名称查找是动态的**：程序运行时，解释器会按照特定顺序搜索多个嵌套的作用域来解析名称 [[1]]。
3. **嵌套作用域结构**：执行过程中至少存在三个可直接访问的嵌套作用域 [[1]]：
   - 最内层：局部命名空间（当前函数）
   - 中间层：所有调用函数的非局部但非全局的命名空间
   - 外层：模块的全局命名空间
   - 最外层：内置命名空间
4. **赋值操作的特性**：如果没有使用`global`声明，赋值操作总是在最内层作用域进行 [[2]]。
5. **作用域控制语句**：使用`global`声明可使名称引用全局作用域 [[1]]；使用`nonlocal`可绑定到外层（非全局）作用域 [[5]]。

2. **创建新的命名空间**：进入类定义部分后，会创建一个新的命名空间作为局部作用域 [[1]][[2]]。在该命名空间内执行的所有赋值语句（包括函数定义）都会成为这个新命名空间的局部变量 [[5]]。

3. **可执行性与放置位置**：类定义是一条可执行语句 [[3]][[4]]。它可以被放置在条件分支（如`if`语句）或函数内部 [[1]][[2]]。

4. **内容与属性绑定**：类定义体（`suite`）中的语句通常是函数定义（即方法），但也可以是其他有用的语句 [[1]][[2]]。类中定义的名称遵 循正常的名称解析规则 [[4]]。当类定义正常退出时，会创建一个类对象，它本质上是对类定义所创建的命名空间进行包装；该类对象随后被绑定到类定义头部指定的类名上 [[5]]。

1. **错误检查与数据类型**：Python提供了比C更多的错误检查，并且作为一种高级语言，它内置了灵活的高级数据类型，如灵活的数组和字典 [[2]]。

异常是一种打断代码块正常控制流程以处理错误或其他意外情况的方法 [[1]]。在Python中，异常在错误被检测到的点引发，并可以通过包围它的代码块或直接、间接调用发生错误的代码块的代码块来处理 [[1]]。

Python解释器在检测到运行时错误（例如除零）时会自动引发一个异常 [[1]]。此外，程序员也可以通过`raise`语句显式地引发异常 [[1]]。异常 处理器通过`try`语句来定义 [[1]]。

标准异常的名称是内置的标识符（不是保留的关键字）[[3]]。当异常发生时，错误消息会指示发生了什么，异常的类型会作为消息的一部分打印出 来，例如`ZeroDivisionError`、`NameError`和`TypeError` [[5]]。打印的异常类型字符串就是内置异常的名称 [[5]]。用户代码也可以引发内置 异常，例如用于测试异常处理程序或报告错误情况 [[2]]。

程序员可以通过从`Exception`类或其子类派生新类来定义新的异常（建议不要从`BaseException`派生）[[2]]。
