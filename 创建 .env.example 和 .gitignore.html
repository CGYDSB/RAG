.env.example 定义了 RAG 系统的环境变量模板，用于管理 OpenAI、Azure OpenAI、Qdrant 和 Redis 等外部依赖配置，避免敏感信息硬编码； .gitignore 则用于排除 Python 编译文件、虚拟环境、日志、数据缓存和 IDE 配置等非代码内容，从而保证代码仓库的干净、安全与可移植性，是标准化生产级项目结构的重要组成部分。 # ========================= # OpenAI API 配置 # ========================= # 用于调用 embedding / LLM（如 GPT-4 / text-embedding） OPENAI_API_KEY=your_openai_api_key_here # ========================= # Azure OpenAI（可选） # ========================= # 如果使用 Azure OpenAI 替代 OpenAI，需要配置以下参数 AZURE_OPENAI_API_KEY=your_azure_key AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/ # ========================= # 向量数据库配置 - Qdrant # ========================= # 用于存储 embedding 向量 QDRANT_HOST=localhost QDRANT_PORT=6333 # ========================= # 缓存数据库 - Redis # ========================= # 用于缓存 query / session / intermediate results REDIS_HOST=localhost REDIS_PORT=6379 REDIS_PASSWORD= # ========================= # 应用运行环境 # ========================= ENVIRONMENT=development # development / production LOG_LEVEL=INFO # DEBUG / INFO / WARNING / ERROR # ========================= # Python 编译产物 # ========================= __pycache__/ *.py[cod] *$py.class *.so # 打包文件 build/ dist/ eggs/ *.egg-info/ # ========================= # 虚拟环境 # ========================= venv/ ENV/ env/ .venv/ # ========================= # IDE 配置文件 # ========================= .vscode/ .idea/ *.swp *.swo *~ # ========================= # 环境变量文件（敏感信息） # ========================= .env .env.local # ========================= # 数据文件（本地缓存/向量库） # ========================= data/chroma_db/ data/qdrant_storage/ *.parquet # ========================= # 日志文件 # ========================= logs/ logs/*.log # ========================= # 操作系统文件 # ========================= .DS_Store Thumbs.db # ========================= # Docker 相关 # ========================= .dockerignore # ========================= # 测试缓存 # ========================= .pytest_cache/ .coverage htmlcov/ # ========================= # 临时文件 # ========================= *.tmp tmp/ temp/
