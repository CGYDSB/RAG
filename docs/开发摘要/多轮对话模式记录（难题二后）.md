函数是用户自定义的可执行代码块，可以通过名称调用。在Python中，函数定义使用 `def` 语句，它会在当前符号表中引入函数名，该名称对应一 个解释器可识别的用户自定义函数对象 [[3]]。函数对象可以分配给其他名称，实现重命名或传递 [[1]]。

函数调用时，实际参数会被引入被调函数的局部符号表，参数传递采用传值调用（传递的是对象的引用）[[1]]。函数内部可以嵌套定义其他函数， 这些内部函数可以被返回或传递，并且能够访问外层函数的局部变量（自由变量）[[2]]。

此外，函数也可以通过 `lambda` 表达式创建，但 `lambda` 表达式定义的函数不能包含语句，而 `def` 语句定义的函数功能更强大，允许执行多 条语句 [[5]]。

以下为基于文档片段的推断：函数作为第一级对象，支持赋值、作为参数传递、从其他函数返回等操作，这增强了代码的模块化和重用性。

助手：根据参考文档，**作用域**是Python中决定变量或名称在何处可被访问的规则集合。它定义了程序执行时名称查找的层次结构。

具体来说：

1. **作用域层次**：程序执行时至少存在三个嵌套的作用域，其命名空间可直接访问 [[1]][[4]]：
   - 最内层：局部命名作用域（如函数内部）
   - 中间层：调用函数的作用域（包含非局部但非全局的名称）
   - 倒数第二层：当前模块的全局命名作用域
   - 最外层：内置命名空间

2. **静态定义与动态查找**：作用域的范围由代码结构静态确定，但名称的实际搜索过程是动态的、在运行时进行的 [[2]][[3]]。例如，函数的全局作用域是它定义所在模块的命名空间，与调用位置无关 [[2]][[3]]。

3. **赋值规则**：如果没有使用 `global` 声明，赋值操作总是在最内层作用域进行 [[2]][[3]]。

4. **作用域控制语句**：
   - `global`：声明名称在模块全局作用域中绑定 [[1]][[4]]
   - `nonlocal`：在嵌套函数中声明名称来自外层（非全局）作用域 [[5]]

5. **示例说明**：文档中的示例展示了 `local`、`nonlocal` 和 `global` 如何影响变量在不同作用域中的绑定 [[5]]。

**关键点总结**：作用域机制确保了名称在不同代码块中的隔离与共享，通过静态作用域定义和动态名称解析相结合的方式工作。

根据参考文档，**类的定义**在Python中是一个可执行的复合语句，用于创建类对象。以下是关键要点：

1. **定义语法与执行**：
   - 类定义使用 `class` 关键字，后跟类名和可选的继承列表，语法为：`"class" classname [inheritance] ":" suite` [[3]]。
   - 它是一个**可执行语句**，需要先执行才能生效。执行时会计算继承序列（如果存在）[[3]]。
   - 类定义可以放置在条件分支（如 `if` 语句）或函数内部 [[1]][[2]]。

2. **命名空间与作用域**：
   - 进入类定义部分后，会**创建一个新的命名空间**，作为局部作用域 [[1]][[2]]。
   - 类定义中定义的名称（如赋值、函数定义）都成为这个新命名空间的局部变量 [[5]]。
   - 类定义的命名空间最终会成为**类的属性字典** [[4]]。
   - 注意：类定义域中定义的名称在类的方法中**不可见**（即方法不能直接访问类定义域中的变量，需要通过类属性或实例属性访问）[[4]]。  

3. **类对象创建**：
   - 类定义正常退出时，会**创建一个类对象**。该类对象本质上是对类定义创建的命名空间的一个包装 [[5]]。
   - 原始的局部作用域（类定义之前生效的作用域）会恢复，类对象会绑定到类定义头部指定的类名上 [[5]]。

4. **内容组成**：
   - 类定义包含的语句通常是函数定义（即方法），但也可以包含其他语句，这些语句在类创建时执行 [[1]][[2]]。
   - 类中的函数定义（方法）通常有特殊形式的参数列表，由方法调用的协议决定 [[1]][[2]]。

**总结**：类定义是一个动态执行的过程，它创建独立的命名空间来封装属性和方法，最终生成一个类对象。其作用域规则使得类内部定义与外部隔离，但通过类对象可访问这些属性。
