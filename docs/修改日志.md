## 2026-04-05

### 无关问题拦截（off-topic detection）

**问题**：用户提问与知识库完全无关时，LLM 会列举检索到的文档内容作为拒答理由，体验差。

**改动**：
- `src/rag_pipeline.py`：pipeline 层加 `off_topic_threshold` 判断，`vector_score` 低于阈值时直接短路返回，不调用 LLM
- `config/prompts.yaml`：`rag_assistant` 规则 6 明确只有日常闲聊才拒答，技术类问题一律尽力作答
- `config/settings.yaml`：新增 `off_topic_threshold: 0.3` 配置项

## 2026-04-06

### 难题一：文档解析与分块优化

参考 RAGFlow v0.24.0 源码，实施策略一（标题层级感知）、策略二（碎片块合并）、策略五（目录页过滤）。

**改动**：

`src/data_loader.py`：
- 新增 `_extract_outline()`：递归遍历 PDF 书签树，提取章节标题和页码
- 新增 `_build_page_to_section()`：按页码区间建立 0-based page → section_title 映射
- 新增 `_detect_toc_pages()`：扫描前 20% 页面，识别目录页并过滤，避免目录条目干扰检索
- `_load_pdf()` 集成以上三个方法，metadata 中写入 `_page_to_section`

`src/document_splitter.py`：
- `RecursiveCharacterSplitter` 新增 `min_chunk_size=50` 参数
- `split()` 从 `_page_to_section` 查表注入 `section_path` 到每个 chunk metadata
- `base_metadata` 过滤非标量类型（修复 ChromaDB 入库异常的根本原因）
- 新增 `_merge_small_chunks()`：合并长度小于 `min_chunk_size` 的碎片块

`src/rag_pipeline.py`：
- `_build_context_with_budget()` 前置 `section_path` 章节名
- `_generate_response()` sources 返回值加入 `section_path`

**相关文档**：`docs/文档解析与分块难题/`

### 难题二：基础召回架构优化

参考 RAGFlow v0.24.0 源码，修复关键词索引未初始化问题，引入中文分词，优化词权重和 Rerank 融合。

**改动**：

`src/retriever.py`：
- `HybridRetriever._tokenize()`：引入 jieba 分词（降级兼容空格切分），新增中文停用词表，名词权重翻倍
- 新增 `save_index()` / `_load_index()`：关键词索引 pickle 持久化，启动时自动加载
- `Reranker.rerank()`：sigmoid 归一化 Cross-Encoder 分数后加权融合（替代简单平均）
- `AdvancedRetriever.retrieve()`：空结果时扩大候选范围重试一次

`src/rag_pipeline.py`：
- `index_documents()` 末尾新增：从向量库读取所有 chunk，重建关键词索引并持久化
- 修复：关键词索引从未初始化，混合检索一直退化为纯向量检索

`main.py`：
- `index` 子命令新增 `--clear` 参数，索引前先清空向量库

**相关文档**：`docs/基础召回架构/`

### Prompt 工程与防幻觉控制优化

参考 RAGFlow v0.24.0 源码对比，实施引用验证、数字幻觉专项约束、chunk 格式化、多轮消歧、引用数量限制。

**改动**：

`src/rag_pipeline.py`：
- 新增 `_fix_citations()`：过滤答案中超出 chunk 范围的引用序号，防止引用幻觉
- 新增 `_rewrite_question()`：多轮对话时检测指代词，调用 LLM 改写为完整问题后再检索
- `_generate_response()`：调用 `_fix_citations()` 对答案做后处理
- `query()`：有对话历史时调用 `_rewrite_question()` 改写检索用问题
- `_build_context_with_budget()`：chunk header 从仅章节名改为文件名 + 章节名

`config/prompts.yaml`：
- `rag_assistant` 新增规则 8：禁止编造数字、百分比、参数值、日期
- `rag_assistant` 新增规则 9：每句最多标注 3 个引用来源
- `conversational` 新增规则 7、8：同上，与 `rag_assistant` 对齐

**相关文档**：`docs/Prompt 工程与防幻觉控制/`
