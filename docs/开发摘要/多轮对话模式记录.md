函数是Python中的一种用户自定义函数对象，可以通过函数定义来创建 [[1]]。  

函数定义使用 `def` 语句，语法为：
`def funcname(parameter_list): suite` [[1]]。

函数是第一级对象，可以被传递、赋值给其他名称或从其他函数返回 [[3]]。例如，`def` 定义的函数可以赋值给另一个变量， 然后通过该变量调用 [[5]]。

lambda 表达式也可以创建函数，但它是函数定义的简写形式，且不能包含语句 [[2][4]]。`def` 形式功能更强大，允许执行多 条语句 [[4]]。

函数调用时，实际参数会被引入被调函数的局部符号表，参数传递采用传值调用（传递的是对象的引用）[[5]]。

助手：根据参考文档，**作用域**是Python中决定变量可见性和生命周期的关键概念。它定义了在代码的哪些部分可以访问特定 的命名（如变量、函数等）。

主要特点包括：

1. **作用域由代码静态确定**：函数的全局作用域是函数定义所在模块的命名空间，与函数调用位置或别名无关 [[1][2]]。   

2. **命名搜索是动态的**：虽然作用域本身是静态确定的，但程序运行时对命名的实际搜索过程是动态的 [[1][2][3]]。不过文档也指出，Python语言可能在未来发展为静态（编译时）确定，因此不建议依赖动态解析 [[1][2]]。

3. **嵌套作用域结构**：程序执行时至少存在三个可直接访问的嵌套作用域（命名空间），搜索顺序为：
   - 最内层局部作用域
   - 外层函数作用域（非局部非全局）
   - 全局作用域（当前模块）
   - 最外层内置命名空间 [[3][5]]

4. **赋值操作的默认行为**：如果没有使用 `global` 或 `nonlocal` 声明，赋值操作总是在最内层作用域进行，且赋值不会复制数据 [[1][2]]。

5. **作用域修改关键字**：
   - `global`：将变量声明为全局，所有引用和赋值直接指向模块全局作用域 [[3][5]]
   - `nonlocal`：用于在嵌套函数中修改外层（非全局）作用域的变量 [[4]]

文档还提供了一个作用域和命名空间的示例，演示了 `global` 和 `nonlocal` 如何影响变量绑定 [[4]]。

根据参考文档，**类的定义**在Python中是一个可执行语句，用于创建类对象。以下是关键要点：

### 1. **定义方式与执行**
- 类的定义使用 `class` 关键字，语法为：`class ClassName [inheritance]: suite` [[3]]。
- 它**必须像函数定义（`def`语句）一样先执行才能生效** [[1][2]]。这意味着类定义可以放在条件分支（如`if`语句）或函 数内部 [[1][2]]。

### 2. **命名空间与作用域**
- 进入类定义部分后，会**创建一个新的命名空间作为局部作用域** [[1][2]]。
- 类定义的命名空间最终会成为类的属性字典 [[4]]。
- 注意：类定义域中定义的名称（如变量）在类的方法中**不可见**，除非通过类或实例显式访问 [[4]]。

### 3. **内容与继承**
- 类定义中的语句通常是函数定义（即方法），但也可以包含其他语句 [[1][2]]。
- 类支持**继承**，派生类定义语法为：`class DerivedClassName(BaseClassName):` [[5]]。
- 继承部分（`BaseClassName`）是可选的，如果存在，会在执行时先计算其表达式列表 [[3]]。

### 4. **与函数定义的类比**
- 类定义在“需先执行”这一点上与函数定义类似 [[1][2]]。
- 但类的方法（内部函数）通常有特殊形式的参数列表（如`self`），由方法调用协议决定 [[1][2]]。

### 5. **类的本质**
- 在Python中，**每个值都是一个对象，并且属于某个类（类型）**，该信息存储为 `object.__class__` [[5]]。

**总结**：类定义是通过 `class` 语句创建类对象的可执行代码块，它建立独立的命名空间，支持继承，并强调“先执行后生效”的特性 [[1][2][3][4][5]]。

根据参考文档，Python与C语言的主要区别体现在以下几个方面：

### 1. **语言特性与易用性**
- Python更简单易用，适用于多种操作系统，能帮助更快地完成工作 [[2]]。
- Python提供了比C更多的错误检查，并内置了高级数据类型（如灵活的数组和字典），使其比C更适用于大型问题领域 [[2]]。 

### 2. **代码结构与语法**
- Python程序通常比等价的C、C++或Java程序更短，原因包括：
  - 高级数据类型允许在单个语句中表达复杂操作。
  - 语句分组通过缩进实现，而非开始和结束括号。
  - 变量或参数无需声明 [[3][4]]。

### 3. **比较操作**
- Python的比较操作与C不同：所有比较操作具有相同的优先级（低于算术、移位和位操作），且类似 `a < b < c` 的表达式符 合数学传统含义 [[1]]。

### 4. **可扩展性**

### 5. **适用场景**
- Python适合用于快速原型开发、编写一次性程序，或在自底向上的开发中测试功能，同时也可用作桌面计算器 [[3][4]]。
